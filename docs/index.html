브이앤엠제이피부과 — 노출 점유율

ChatGPT · Gemini에게 매일 질문을 던지고, AI 답변 본문에 실제로 추천/언급된 경우만 노출로 집계합니다. 날짜를 넘겨가며 우리 병원과 경쟁 병원의 노출 변화를 확인하세요.
노출 판정 기준 — 검색 결과·출처 각주에 병원명이 등장한 것만으로는 노출로 인정하지 않습니다. AI의 최종 답변 본문에서 실제로 추천되거나 언급된 경우에만 집계하며, 확인되지 않은 결과는 추측하지 않습니다.

측정 방법 & 한계

어떻게 측정하나요

매일 자동화된 스크립트가 질문을 ChatGPT·Gemini 공식 API에 웹검색 도구를 켠 상태로 전송하고, Gemini를 심판으로 세워 "본문에 실제로 추천/언급됐는가"만 엄격히 채점합니다. 로그인 개인화의 영향을 받지 않습니다.

노출 점유율 계산법

해당 기간의 유효 실행(질문 × 플랫폼 × 일수) 중 우리 병원이 실제 노출된 비율입니다. 브랜드 랭킹의 각 % 역시 같은 방식(그 브랜드가 언급된 실행 비율)으로 계산됩니다.

소비자용 앱과의 차이

이 결과는 공식 API 기준입니다. chatgpt.com·gemini.google.com 같은 소비자용 웹/앱은 지도·업체 평점 카드 등 API에 없는 요소가 추가로 반영될 수 있어 실제 화면과 다소 다를 수 있습니다.

오류 처리

특정 플랫폼 호출이 실패하면 "확인 오류"로 표시하고 집계에서 제외하며, 이를 미언급으로 간주하지 않습니다.
